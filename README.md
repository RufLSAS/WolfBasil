# Wolf Basil — лендинг услуги оформления зарубежных карт

Одностраничный самодостаточный сайт: весь CSS, JS и шрифты встроены в один файл `index.html` (~391 КБ). Внешних запросов нет — страница работает офлайн и на любом хостинге.

**Сайт опубликован через GitHub Pages: <https://ruflsas.github.io/WolfBasil/>**

## Структура

- `index.html` — весь сайт
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages (файл отдаётся как есть)

## Обновление сайта

Замените `index.html` новой версией и отправьте изменения:

```bash
git add index.html
git commit -m "Обновление: <что изменилось>"
git push
```

GitHub Pages подхватит новую версию автоматически в течение пары минут. Источник Pages настроен в Settings → Pages: ветка `main`, папка `/ (root)`.

## Что внутри сайта

- Тёмная и светлая темы (переключатель в шапке, выбор запоминается)
- Адаптивная вёрстка: телефон, планшет, десктоп
- Анимации появления блоков при прокрутке, плавная смена темы
- Метатеги Open Graph для превью ссылки в мессенджерах
